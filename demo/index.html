Human activity recognition · Hidden Markov Models

Phone Activity HMM

A phone worn on the waist records how its owner moves. From those sensor readings, six Hidden Markov Models, one per activity, decide whether the person is laying, sitting, standing, walking, or walking down or up stairs. A Logistic Regression is trained on the same inputs as a comparison. Every number and plot below comes from one run of the pipeline in this repository on the UCI dataset.

Input

What the model receives

The phone's accelerometer and gyroscope are sampled at 50 Hz. The signal is cut into 2.56 s windows (128 samples, 50% overlap), and each window is summarised as 561 numbers scaled to −1…1: means, deviations, energies, frequency bands and angles. One row of the CSV is one window. The model never sees raw waveforms.

Four of the 561 features over time,

Each point is one 2.56 s window. The background shows the true activity. Movement intensity separates the walking activities from the still ones, and gravity along X (posture) singles out laying.

Method

From 561 numbers to one activity

The scaler, the PCA and every model are fitted on the training volunteers only. The test volunteers are never seen during training.

The compressed feature space (first 2 of PCA components)

Inside one activity's HMM

Each HMM has hidden states, sub-phases of the activity that the model discovers by itself. It learns how likely each state is to follow another (below), and what sensor values each state produces (the S markers on the plot).

Output

Predictions on unseen volunteers

The test windows are cut into chunks of consecutive windows (about s). All six HMMs score each chunk, and the activity whose model explains it best wins. Logistic Regression labels each window on its own. Click any chunk on the timeline to see the decision.

Scores on all 2,947 test windows

F1 per activity: the balance of precision and recall, where 1.0 is perfect. Logistic Regression wins here. Each row is already a 2.56 s summary, so most of the information sits inside one window, and a 16-window chunk that crosses an activity change can only get one label.

Where the mistakes go

Rows are the true activity and columns the prediction (window counts). The diagonal is correct. Most confusion is sitting vs standing, and between the three walking activities.

Data: UCI Human Activity Recognition Using Smartphones (30 volunteers, Samsung Galaxy S II on the waist). The official split has 21 volunteers for training and 9 for testing.
